# Библиотека репринтов — статический PWA-сайт

Сайт не требует базы данных или собственного сервера. Достаточно загрузить содержимое папки `site` на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages или аналогичный сервис.

Дизайн адаптирован под визуальную систему Ingal Cosmetics: фирменный логотип, Gilroy, красно-серая палитра и модульная подача материалов. Логотип и шрифт размещены локально в папке `assets`, поэтому они входят в PWA-кэш.

## Локальный просмотр

PWA и встроенный просмотр PDF требуют открытия через HTTP, а не двойным щелчком по `index.html`.

Пример с Python:

```powershell
python -m http.server 8080 --directory site
```

После запуска откройте `http://localhost:8080`.

## Публикация

### GitHub Pages

1. Создайте репозиторий и загрузите в него содержимое папки `site`.
2. В Settings → Pages выберите публикацию из ветки `main` и папки `/ (root)`.
3. Дождитесь появления публичного адреса.

### Netlify

Перетащите папку `site` в окно ручного развёртывания Netlify Drop.

## Установка на телефон

- Android / Chrome: кнопка «Установить приложение» или пункт «Добавить на главный экран».
- iPhone / Safari: «Поделиться» → «На экран Домой».

Каталог и интерфейс кэшируются для офлайн-запуска. PDF хранятся на Google Drive, поэтому их просмотр и скачивание требуют интернета.
